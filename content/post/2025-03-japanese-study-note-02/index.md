## <ruby>辭書形<rp></rp><rt>じしょけい</rt><rp></rp></ruby> vs <ruby>丁寧語<rp></rp><rt>ていねいご</rt><rp></rp></ruby>

**<ruby>辭書形<rp></rp><rt>じしょけい</rt><rp></rp></ruby> — 字典形式**

動詞的基本形，也是最原始的形式，就像字典裡收錄的那樣，因此叫做「辭書形」。常用於：
- 講述事實或中性敘述：
    - 勉強する。（學習）
    - 食べる。（吃）
    - 行く。（去）
- 和朋友、家人之間的輕鬆對話，語氣比較直接。

**<ruby>丁寧語<rp></rp><rt>ていねいご</rt><rp></rp></ruby> — 禮貌形式** 

這種形式語氣更有禮貌，適合用在職場、學校、跟長輩或不太熟的人對話。

動詞變化的概念大概如下⬇️
辭書形 → ます形：
- 勉強する → 勉強します。（學習）
- 食べる → 食べます。（吃）
- 行く → 行きます。（去）

> 「明日東京へ行く。」（明天去東京。）—— 比較普通、適合對朋友講。
>
> 「明日東京へ行きます。」（明天去東京。）—— 更有禮貌，適合對老師、上司講。

## <ruby>丁寧語<rp></rp><rt>ていねいご</rt><rp></rp></ruby> 動詞變化

### 一類動詞（五段動詞）

> 「五段」指的是動詞在變化（未然形、連用形、終止形、假定形、命令形、意向形）時，它的語幹結尾的音會在五個母音段之間變化。
>
> 這邊只專注在丁寧語。

#### 沒有主詞的句子
以下以喝這個動詞為範例，可以發現句子裡都沒有主詞。

- <ruby>水<rp></rp><rt>みず</rt><rp></rp></ruby>を<ruby>飲<rp></rp><rt>の</rt><rp></rp></ruby>みます。(喝水。 ) 
- <ruby>ジュース</ruby>を<ruby>飲<rp></rp><rt>の</rt><rp></rp></ruby>みます。(喝果汁。 ) 
- <ruby>牛乳<rp></rp><rt>ぎゅうにゅう</rt><rp></rp></ruby>を<ruby>飲<rp></rp><rt>の</rt><rp></rp></ruby>みます。(喝牛奶。)  
- <ruby>薬<rp></rp><rt>くすり</rt><rp></rp></ruby>を<ruby>飲<rp></rp><rt>の</rt><rp></rp></ruby>みます。(吃藥。  )

所以主詞是誰，不知道!?!? 要看上下文。

1. 「私（わたし）」 —— 如果是 **自己** 在說話， default 主詞通常是「我」。
    例：

    <ruby>水<rp></rp><rt>みず</rt><rp></rp></ruby>を<ruby>飲<rp></rp><rt>の</rt><rp></rp></ruby>みます。（我喝水。）

2. 「あなた」 —— 如果是在 **問對方**，主詞通常是「你」。
    例：

    ジュースを<ruby>飲<rp></rp><rt>の</rt><rp></rp></ruby>みますか？（你喝果汁嗎？）

3. 第三人稱 —— 如果上下文已經明確提到別人，主詞就會是那個人。
    例：

    <ruby>田中<rp></rp><rt>たなか</rt><rp></rp></ruby>さんは<ruby>牛乳<rp></rp><rt>ぎゅうにゅう</rt><rp></rp></ruby>を<ruby>飲<rp></rp><rt>の</rt><rp></rp></ruby>みます。（田中喝牛奶。）

### <ruby>取<rt>と</rt></ruby>る vs <ruby>持<rt>も</rt></ruby>つ

**<ruby>取<rt>と</rt></ruby>る**

意思：拿、取、拿起

強調：「從某個地方拿取某樣東西」，動作瞬間發生。

例句：

<ruby>コップ</ruby>を<ruby>取<rt>と</rt></ruby>ります。（拿杯子。——強調動作 "拿起來"。）

<ruby>机<rt>つくえ</rt></ruby>の<ruby>上<rt>うえ</rt></ruby>の<ruby>本<rt>ほん</rt></ruby>を<ruby>取<rt>と</rt></ruby>ってください。（請拿桌上的書。）

> 👉 取る 多用在短暫的「拿起」行為，完成後就不再持有。

**<ruby>持<rt>も</rt></ruby>つ**

意思：拿、持有、攜帶

強調：「持續地拿著某東西」，動作是持續的狀態。

例句：

<ruby>カバン</ruby>を<ruby>持<rt>も</rt></ruby>ちます。（拿著包包。——強調 "保持拿著" 的狀態。）

<ruby>傘<rt>かさ</rt></ruby>を<ruby>持<rt>も</rt></ruby>っていきます。（帶著傘去。）

> 👉 持つ 更強調「保持拿著、攜帶」的持續性，而不是瞬間的「拿起來」。

### 二類動詞（上一段、下一段動詞）
第二類動詞的辭書形以`る`結尾，`る`前面的音是 `い段`（上一段）或 `え段`（下一段），所以比起第一類動詞稱為五段，第二類動詞則只有一段！

✅ 上一段例子：
- <ruby>見<rp></rp><rt>み</rt><rp></rp></ruby>る → <ruby>見<rp></rp><rt>み</rt><rp></rp></ruby>ます
- <ruby>起<rp></rp><rt>お</rt><rp></rp></ruby>きる → <ruby>起<rp></rp><rt>お</rt><rp></rp></ruby>きます

✅ 下一段例子：
- <ruby>食<rp></rp><rt>た</rt><rp></rp></ruby>べる → <ruby>食<rp></rp><rt>た</rt><rp></rp></ruby>べます
- <ruby>出<rp></rp><rt>で</rt><rp></rp></ruby>る → <ruby>出<rp></rp><rt>で</rt><rp></rp></ruby>ます

| <ruby>見<rp></rp><rt>み</rt><rp></rp></ruby>る | <ruby>見<rp></rp><rt>み</rt><rp></rp></ruby>ます | 看 | <ruby>映画<rp></rp><rt>えいが</rt><rp></rp></ruby>を<ruby>見<rp></rp><rt>み</rt><rp></rp></ruby>ます。| 看電影 |
