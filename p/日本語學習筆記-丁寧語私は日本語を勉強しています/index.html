日本語學習筆記 丁寧語——私は日本語を勉強しています

Mar 11, 2025
閱讀時間: 4 分鐘

我媽買的課程因為主要是旅遊目的，因此動詞變化好像只有教丁寧語 XD

辭書形じしょけい vs 丁寧語ていねいご

辭書形じしょけい — 字典形式

動詞的基本形，也是最原始的形式，就像字典裡收錄的那樣，因此叫做「辭書形」。常用於：

  • 講述事實或中性敘述：
    • 勉強する。（學習）
    • 食べる。（吃）
    • 行く。（去）
  • 和朋友、家人之間的輕鬆對話，語氣比較直接。

丁寧語ていねいご — 禮貌形式

這種形式語氣更有禮貌，適合用在職場、學校、跟長輩或不太熟的人對話。

動詞變化的概念大概如下⬇️ 辭書形 → ます形：

  • 勉強する → 勉強します。（學習）
  • 食べる → 食べます。（吃）
  • 行く → 行きます。（去）

「明日東京へ行く。」（明天去東京。）—— 比較普通、適合對朋友講。

「明日東京へ行きます。」（明天去東京。）—— 更有禮貌，適合對老師、上司講。

丁寧語ていねいご 動詞變化

一類動詞（五段動詞）

以う段結尾的動詞（基本都是五段動詞，丁寧語動詞變化的規則是將動詞的最後一個う段變い段，再加上ます。

「五段」指的是動詞在變化（未然形、連用形、終止形、假定形、命令形、意向形）時，它的語幹結尾的音會在五個母音段之間變化。

這邊只專注在丁寧語。

沒有主詞的句子

以下以喝這個動詞為範例，可以發現句子裡都沒有主詞。

  • 水みずを飲のみます。(喝水。 )
  • ジュースを飲のみます。(喝果汁。 )
  • 牛乳ぎゅうにゅうを飲のみます。(喝牛奶。)
  • 薬くすりを飲のみます。(吃藥。 )

所以主詞是誰，不知道!?!? 要看上下文。

  1. 「私（わたし）」 —— 如果是 自己 在說話， default 主詞通常是「我」。 例：

    水みずを飲のみます。（我喝水。）

  2. 「あなた」 —— 如果是在 問對方，主詞通常是「你」。 例：

    ジュースを飲のみますか？（你喝果汁嗎？）

  3. 第三人稱 —— 如果上下文已經明確提到別人，主詞就會是那個人。 例：

    田中たなかさんは牛乳ぎゅうにゅうを飲のみます。（田中喝牛奶。）

取とる vs 持もつ

取とる

意思：拿、取、拿起

強調：「從某個地方拿取某樣東西」，動作瞬間發生。

例句：

コップを取とります。（拿杯子。——強調動作 “拿起來”。）

机つくえの上うえの本ほんを取とってください。（請拿桌上的書。）

👉 取る 多用在短暫的「拿起」行為，完成後就不再持有。

持もつ

意思：拿、持有、攜帶

強調：「持續地拿著某東西」，動作是持續的狀態。

例句：

カバンを持もちます。（拿著包包。——強調 “保持拿著” 的狀態。）

傘かさを持もっていきます。（帶著傘去。）

👉 持つ 更強調「保持拿著、攜帶」的持續性，而不是瞬間的「拿起來」。

二類動詞（上一段、下一段動詞）

第二類動詞的辭書形以る結尾，る前面的音是 い段（上一段）或 え段（下一段），所以比起第一類動詞稱為五段，第二類動詞則只有一段！

✅ 上一段例子：

  • 見みる → 見みます
  • 起おきる → 起おきます

✅ 下一段例子：

  • 食たべる → 食たべます
  • 出でる → 出でます
